
# RAG-Based Document Retrieval Assistant

## Project Overview
A simple Python-based document retrieval system that uses TF-IDF Vectorization and Cosine Similarity to find relevant information from a JSON knowledge base.

## Technologies Used
- Python
- Scikit-learn
- TF-IDF Vectorization
- Cosine Similarity
- JSON

## Project Structure

RAG_project/
├── data/
│   └── knowledge.json
├── main.py
├── requirements.txt
└── README.md

## Features
- Loads documents from a JSON file.
- Converts documents into TF-IDF vectors.
- Finds relevant documents using Cosine Similarity.
- Retrieves the most relevant document based on user questions.

## Installation

Install dependencies:

pip install -r requirements.txt

## Run the Project

python main.py
